# AIN-001 — Autonomous Intelligence Newsroom

## Thesis
Build a Google News-style aggregation and event-clustering product focused first on African business and economic intelligence, then add an intelligence layer that converts news into economically meaningful signals.

## Core chain
NEWS → EVENT → ECONOMIC SIGNIFICANCE → COMPANIES / MARKETS AFFECTED → OPPORTUNITY → ACTION

## Operating pipeline
Source registry → collection → extraction / normalization → event clustering → provenance → verification → ranking → summarization → categorization → publishing → monitoring → learning.

## Target autonomy
- L1: aggregator
- L2: intelligence aggregator
- L3: autonomous newsroom
- L4: intelligence newsroom
- L5: opportunity engine feeding qualified signals into the Factory

## Current state
Standalone UI prototype migrated into this repository. Prototype story data is synthetic and must not be presented as live reporting.

## Next milestone
Connect a small real source set, persist normalized articles and event clusters, and prove that the system can autonomously produce accurate, source-linked event summaries and useful opportunity signals.
